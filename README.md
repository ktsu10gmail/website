# Jetta Marketing Website

Public marketing website for Jetta at https://www.jetta.com.

This site is separate from the Jetta application at
https://golfgame.jetta.com. See `CODEX_CONTEXT.md` before making content or
architecture changes.

## WordPress

This repository tracks the custom Jetta WordPress block theme at
`wp-content/themes/jetta`. WordPress core, uploads, local configuration, caches,
database dumps, and secrets are intentionally ignored.
